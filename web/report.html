统计口径：
帧时间 P95 = 各报告点的0.5s 短窗 P95 峰值再求均值（非全体帧 P95）
卡顿率 = Σjank_count / Σjank_total（按全部有效帧间隔加权）
旧版 JSONL 无短窗字段时，自动回退逐点算术平均口径
网络 = 整机流量（除 lo），非进程级
Jank 判定 = 2 × 节奏 × 1.1；节奏 = 帧间隔中位数吸附 60/90/120/144Hz 档（10% 容差）
FPS = 0.5s gap 切段取帧数最多主段，主段 (帧数−1) / span
FPS 口径 = 上屏帧率（SurfaceFlinger，受屏幕刷新率封顶，60Hz 屏≤60）；引擎/开发者工具的「渲染循环帧率」是另一口径（可达 61~63），数值对不上属正常

帧时间 P50≈P95≈Max（如 16.7 / 16.8 / 17.2ms）在无卡顿窗口属正常——只统计新增帧
